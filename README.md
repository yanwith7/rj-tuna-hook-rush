# RJ 的黄金鱼汛：Tuna Hook Rush

一个无后端、无登录、手机优先的竖屏像素风跑酷小游戏。RJ 在三车道沙滩自动向前跑；左右换道、跳跃或滑铲躲开障碍，同时看准上方黄金钩爪的角度，抓住跃出海面的金枪鱼。

## 直接运行

这是零依赖的静态站点，`dist/` 就是最终构建产物。

在本目录执行任一静态服务器即可：

```bash
python3 -m http.server 8080 --directory dist
```

然后打开 `http://localhost:8080`。也可以直接打开 `dist/index.html` 查看画面；为确保移动端音频和分享逻辑一致，建议通过静态服务器运行。

## 操作

- 手机：左右滑换道；上滑跳跃；下滑滑铲；轻点发钩；中鱼、大鱼咬钩后连点收线；长按可手动调节钩爪角度，松手发射。
- 桌面：方向键控制移动、跳跃和滑铲；空格发钩／收线；鼠标点击发钩／收线；Esc 暂停。
- 钩爪自动在 `-55°` 到 `+55°` 间摆动。鱼处于同一跃出线且角度误差不超过 `±15°` 时可命中。

## 玩法与状态

- 单局 75 秒；速度会从 8 m/s 平滑提高，最高为 14 m/s。
- 小／中／大金枪鱼分别提供 10／50／200 分；中鱼收线要 3 次连点，大鱼要 5 次连点。
- 水母、礁石、渔网都可造成一次警告。渔网会减速并要求连点挣脱。
- 初始有 3 个贝壳护盾。每次受击后 1.5 秒无敌；第三次受击依次播放最高优先级警告与失败语音并进入 Game Over。
- 最高分、累计金币、音量、语音开关和语音频率保存在浏览器本地存储中。

## 语音文件与固定事件 ID

所有语音事件和文件路径集中在 [`dist/config.js`](dist/config.js)。当前文件由用户提供的 MOV 语音转换为浏览器可播放的 AAC/M4A：

| 事件 ID | 当前文件 | 触发 |
| --- | --- | --- |
| `SUCCESS` | `assets/audio/success.m4a` | 普通成功抓鱼 |
| `SUCCESS_RARE` | `assets/audio/success.m4a` | 稀有大鱼 |
| `WARNING_1` | `assets/audio/warning.m4a` | 第一次受击 |
| `WARNING_2` | `assets/audio/warning.m4a` | 第二次受击 |
| `WARNING_3` | `assets/audio/warning.m4a` | 第三次受击 |
| `GAME_OVER` | `assets/audio/gameover.m4a` | 失败结算 |

要替换语音，只需用同名 `.m4a` 文件覆盖 `dist/assets/audio/` 中的文件，或在 `dist/config.js` 中修改路径。普通成功语音有 15 秒全局冷却；每一条事件也有独立冷却，语音管理器会让高优先级语音覆盖低优先级语音，避免重叠。

## 替换美术

- `dist/assets/images/rj-runner.png`：透明底 RJ 跑酷角色。
- `dist/assets/images/tuna-sprites.png`：从左到右为小鱼、中鱼、大鱼的透明底横向精灵图。

保持 PNG 透明背景最稳妥。更换文件后无需构建；刷新浏览器缓存即可。角色和鱼的绘制尺寸在 `dist/game.js` 中，分数、体重、稀有度与难度在 `dist/config.js` 中。

## 调整数值

所有核心数值都在 `dist/config.js`：局时长、速度曲线、鱼／障碍概率、钩爪角度、命中宽容、护盾、无敌时间、金币、分数、连点次数和语音冷却均可直接调整。

## 部署与分享

无需构建命令。将 `dist/` **里面的内容**部署到任意静态托管即可，入口必须保持为 `index.html`：

- GitHub Pages：将 `dist/` 发布为 Pages 的静态根目录。
- Netlify / Vercel / Cloudflare Pages：选择静态站点，发布目录填写 `dist`，无需构建命令。
- itch.io：把 `dist/` 中的所有文件压缩为 ZIP，确保 ZIP 根目录直接有 `index.html`；上传时选择 **HTML Game** 并建议开启全屏启动。

所有资源均使用相对路径，因此上述平台的子路径、CDN 和手机浏览器均可打开。结算页的“分享链接”会复制当前页面地址。
